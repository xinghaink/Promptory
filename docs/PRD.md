## 1. 需求分析

### 1.1 目标用户

| 用户 | 场景 | 核心诉求 |
| --- | --- | --- |
| 个人重度用户（开发者、产品、运营、内容创作者） | 每天在多个 AI 网站中反复使用相似提示词 | 快速找到、在输入框里直接用 |
| 提示词“调优者” | 为某个任务反复迭代提示词 | 版本管理、知道哪版更好 |
| 小团队（P2） | 共享沉淀好用的提示词 | 共享、权限 |

MVP 聚焦**个人重度用户**。

### 1.2 痛点（经调研验证）

1. **散落、找不到**：存在备忘录、聊天记录、收藏夹里，收藏了就再也找不到。
2. **整理成本高**：手动归档是“第二份工作”，坚持不下去。
3. **复用摩擦大**：要在管理工具和 AI 网站之间来回复制粘贴，还要手动改变量。
4. **迭代无记录**：不知道哪版效果最好，改坏了无法回退。

### 1.3 定位与差异化

- **定位**：本地优先、跨 AI 平台的个人提示词库，以浏览器插件为载体。
- **相对插件类竞品**：跨平台（不只 ChatGPT），无广告，变量真能就地填写，有版本和效果反馈。
- **相对 Raycast 等启动器**：能在网页输入框里暂停下来填变量；有版本管理。
- **相对 Langfuse 等开发者平台**：不接 SDK、零概念负担，只借鉴“推荐版本 + 反馈”。
- **相对笔记工具**：有变量、版本和一键插入。

### 1.4 成功指标

- 北极星：**每周插入 / 复制次数**。
- 辅助：收藏数（尤其右键收藏）、收件箱整理率、“好用”比例、7 日留存。
- 上手指标：新用户 **5 分钟内**完成第一次“收藏 → 插入”。

## 2. 功能设计

### 2.1 产品形态

一个 Chrome / Edge 插件，包含三个入口，数据都存在本地：

1. **网页内唤起**：在 AI 网站输入框中输入 `/` 或按快捷键。
2. **右键收藏**：在任意网页选中文字后保存。
3. **完整管理页**：插件自带的全屏页面，用于整理、编辑和查看版本。

### 2.2 功能清单与优先级

| 模块 | 功能 | 优先级 |
| --- | --- | --- |
| 就地使用 | AI 网站输入框内 `/` 唤起，按快捷词或关键词筛选，就地填变量，插入（或插入并发送）；支持主流 AI 网站 | **P0（新增）** |
| 快速收藏 | 右键 / 快捷键保存选中文本；自动生成标题、建议标签、识别可替换内容并转为变量；记录来源网址；默认进入收件箱 | **P0（新增）** |
| 提示词库 | 新建 / 编辑 / 删除（回收站）、收藏、复制原文、收件箱待整理 | P0 |
| 组织 | 文件夹、标签、适用模型、快捷词（如 `/zb`） | P0 |
| 变量 | `{{变量}}` 自动识别；类型：单行 / 多行 / 下拉；默认值；记住上次填写 | P0 |
| 内置变量 | `{{@剪贴板}}` `{{@选中文本}}` `{{@今天}}` `{{@现在}}` 自动填充 | **P0（新增）** |
| 片段 | `{{>片段}}` 引用可复用片段 | P1 |
| 搜索 | 标题 / 内容 / 标签搜索、模糊匹配、按使用频率排序；⌘K 快速搜索 | P0 |
| 版本 | 保存即生成版本 + 修改说明；差异对比；恢复为新版本；**★ 推荐版本**（插件默认使用它） | P0（推荐版本为新增） |
| 反馈 | 使用后一键“好用 / 不好用”，按版本统计 | **P0（新增，轻量）** |
| 数据 | 本地存储；导入 AIPRM / CSV / Markdown / Raycast JSON；导出 JSON / Markdown | P0 |
| 测试台 | 自带 API Key 运行、多版本 / 多模型对比 | P1 |
| 智能 | 语义搜索、AI 改写 / 优化提示词 | P1 |
| 同步与协作 | 可选云同步（自选存储）、团队空间、分享链接 | P2 |

### 2.3 核心对象（数据模型草案）

```
Prompt   { id, title, description, content, folderId, tags[], models[],
           shortcut, variables[], isFavorite, inInbox, sourceUrl,
           recommendedVersion, latestVersion, useCount, lastUsedAt,
           createdAt, updatedAt, deletedAt }
Variable { name, type: text|textarea|select, default, options[], lastValue }
Version  { id, promptId, number, content, variables[], note,
           useCount, goodCount, badCount, createdAt }
Folder   { id, name, order }
Snippet  { id, name, content }            // P1
```

### 2.4 关键规则

- 变量语法：`{{名称}}` 由用户填写；`{{@名称}}` 由系统自动填充；`{{>名称}}` 引用片段。
- 草稿自动保存，但不生成版本；点击“保存”才生成版本。
- 推荐版本默认跟随最新版本（大多数人不需要关心它）；用户把某个旧版本“设为推荐”后就固定在该版本，直到再次手动调整。插件和快捷词默认使用推荐版本。
- 恢复历史版本时，以该内容生成一个新版本，不改写历史。
- 收藏默认进入收件箱；在收件箱中整理（改标题、移入文件夹）后移出。
- 删除进入回收站，30 天后清除。
- 隐私：数据默认只存在本地，不强制注册；插件只申请 AI 网站域名的权限，右键收藏仅在用户主动操作时读取选中文本。

## 3. 原型页面

1. **提示词库（管理页首页）**：新增收件箱、插件状态入口、推荐版本 / 反馈 / 快捷词信息。
2. **编辑提示词**：新增内置变量面板和快捷词设置。
3. **填写变量并使用**：主按钮改为“插入到对话框”，自动填充内置变量。
4. **版本历史**：新增推荐版本标记、每个版本的使用和反馈统计、“设为推荐版本”。
5. **⌘K 快速搜索**。
6. **（新）插件：在 AI 网站输入 `/` 唤起**：左侧选择提示词，右侧就地填写变量，回车插入。
7. **（新）插件：右键一键收藏**：自动标题、识别可替换内容并转为变量，保存到收件箱。

## 4. 已确认的决策

1. 形态：浏览器插件（Chrome / Edge，Manifest V3）+ 插件内置的管理页。
2. 首批支持：ChatGPT、Claude、Gemini、DeepSeek、豆包、Kimi。
3. 收藏时的自动标题、标签、变量识别先用本地规则实现；接入用户自己的 API Key 做增强放到 P1。
4. 技术栈：React + TypeScript + WXT + Dexie（IndexedDB）。

## 5. 已知限制

- 插入输入框依赖各网站的编辑器实现（textarea、ProseMirror 等），网站改版后可能需要适配；没有找到输入框时会改为复制到剪贴板。
- 在 AI 网站中读取剪贴板可能被浏览器拦截，此时面板里的「剪贴板」一项为空，可以手动粘贴。
- 数据只存在当前浏览器中，清除浏览器数据会丢失，需要定期导出备份（云同步为 P2）。
