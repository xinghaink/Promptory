# Promptory 产品需求文档（v0.1 · 待确认）

> 一个面向 AI 重度用户的提示词管理工具：**存得下、找得到、用得快、改得清**。

原型图：https://claude.ai/artifact/94JD8JyBfxRBbKeQL8tH5m

---

## 1. 需求分析（产品思维）

### 1.1 目标用户

| 用户 | 场景 | 核心诉求 |
| --- | --- | --- |
| 个人重度用户（开发者、产品、运营、内容创作者） | 每天在 ChatGPT / Claude 等多个工具中反复使用相似提示词 | 快速找到、快速复用 |
| 提示词“调优者”（AI 应用开发者） | 为某个任务反复迭代提示词 | 版本管理、效果对比 |
| 小团队（P2） | 团队共享沉淀好用的提示词 | 共享、规范、权限 |

MVP 聚焦**个人重度用户**，团队协作放到后续版本。

### 1.2 现状痛点

1. **散落**：提示词存在备忘录、聊天记录、文档、IDE 里，用时找不到。
2. **复用成本高**：好用的提示词每次都要复制后手动改人名、主题等“变量”，容易漏改。
3. **迭代无记录**：改了几版后不知道哪版效果最好，改坏了无法回退。
4. **难以沉淀**：没有分类和标签，数量一多就变成“垃圾堆”。

### 1.3 产品定位与核心价值

- **定位**：本地优先（Local-first）的个人提示词库，Web 应用起步。
- **核心流程**：找到 → 填变量 → 复制使用 → 迭代版本。
- **一句话价值**：3 秒内找到并用上你最好的那条提示词。

### 1.4 竞品与差异化

| 方式 | 不足 | Promptory 的做法 |
| --- | --- | --- |
| 备忘录 / Notion | 无变量、无版本、复用要手改 | 变量模板 + 一键填充 |
| 各 AI 工具自带的“自定义指令” | 绑定单一平台，数量有限 | 跨平台、无限数量 |
| 提示词社区网站 | 偏“发现”，不适合管理自己的库 | 以“我的库”为中心 |

### 1.5 成功指标（MVP）

- 北极星指标：**每周“使用”（填变量复制）次数**。
- 辅助指标：提示词保存数、搜索到使用的转化率、7 日留存。

## 2. 功能设计

### 2.1 功能清单与优先级

| 模块 | 功能 | 优先级 |
| --- | --- | --- |
| 提示词库 | 新建 / 编辑 / 删除（回收站）、收藏、复制原文 | P0 |
| 组织 | 文件夹（单层）、多标签、适用模型标记 | P0 |
| 变量模板 | `{{变量}}` 自动识别；类型：单行 / 多行 / 下拉选项；默认值 | P0 |
| 使用 | 填写变量表单 + 实时预览 + 一键复制；记住上次填写 | P0 |
| 搜索 | 标题 / 内容 / 标签全文搜索，按文件夹、标签、模型筛选；⌘K 全局快速搜索 | P0 |
| 版本 | 每次保存生成版本 + 修改说明；版本差异对比；恢复为新版本 | P0 |
| 数据 | 本地存储；JSON / Markdown 导入导出 | P0 |
| 测试台 | 配置 API Key，直接运行提示词、多模型 / 多版本对比输出 | P1 |
| 效率 | 浏览器插件：在 AI 网站输入框中唤起并插入提示词；从剪贴板快速保存 | P1 |
| 统计 | 使用次数、最近使用、常用排行 | P1 |
| 片段 | 可复用片段（如“输出格式要求”）被多个提示词引用 | P1 |
| 协作 | 云同步、团队空间、分享链接、权限 | P2 |

### 2.2 核心对象（数据模型草案）

```
Prompt   { id, title, description, content, folderId, tags[], models[],
           variables[], isFavorite, useCount, lastUsedAt, currentVersion,
           createdAt, updatedAt, deletedAt }
Variable { name, type: text|textarea|select, default, options[] }
Version  { id, promptId, number, content, variables[], note, createdAt }
Folder   { id, name, order }
```

### 2.3 关键规则

- 变量语法 `{{名称}}`，编辑时自动识别；新出现的变量默认类型为单行文本。
- “保存”生成新版本；草稿自动保存但不产生版本，避免版本泛滥。
- 恢复历史版本 = 以该内容生成一个新版本，历史不被改写。
- 删除进入回收站，30 天后清除。

## 3. 原型页面（见原型图链接）

1. **提示词库（首页）**：左侧导航（全部 / 收藏 / 最近 / 文件夹 / 标签），中间列表，右侧详情预览与“使用”入口。
2. **编辑提示词**：内容编辑区（变量高亮、插入变量、字数 / tokens 估算）+ 右侧属性面板（描述、文件夹、标签、模型、变量配置、修改说明）。
3. **填写变量并使用**：左侧变量表单，右侧实时预览，一键复制。
4. **版本历史与对比**：版本列表 + 行内差异对比 + 恢复。
5. **⌘K 快速搜索**：键盘优先，搜索后回车直接进入“填写并使用”。
